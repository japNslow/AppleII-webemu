# Apple II+ Web Emulator

[![GitHub Pages Deployment](https://img.shields.io/badge/GitHub%20Pages-Ready-brightgreen.svg)](https://japNslow.github.io/AppleII-webemu/)
[![MOS 6502](https://img.shields.io/badge/CPU-MOS%206502-orange.svg)]()
[![Pure Web](https://img.shields.io/badge/Architecture-Pure%20HTML5%20%2F%20ES6-blue.svg)]()

Полнофункциональный, аутентичный веб-эмулятор **Apple II Plus**, написанный с нуля на чистом JavaScript (ES6 Modules) и HTML5 Canvas/Web Audio API. Полностью готов к публикации на **GitHub Pages** без необходимости серверной сборки (zero-build, zero-dependencies).

---

## 🌟 Возможности

### 🖥️ Аппаратное ядро (MOS 6502 & Apple II Architecture)
- **Процессор MOS 6502**:
  - Полный набор инструкций (все 56 официальных инструкций и адресаций).
  - Точная арифметика десятичного режима (BCD) для `ADC` и `SBC` (NMOS-логика).
  - Точный подсчет циклов (~1.020484 МГц) с поддержкой ускорения (1x, 2x, 4x, 8x Fast-Forward).
  - Векторы прерываний: Reset (`$FFFC`), IRQ/BRK (`$FFFE`), NMI (`$FFFA`).
- **Память и софт-свитчи (MMU)**:
  - 48 КБ основной памяти RAM (`$0000` - `$BFFF`).
  - 16 КБ расширения Language Card RAM (`$D000` - `$FFFF`, Bank 1 / Bank 2).
  - Аппаратные софт-свитчи `$C000` - `$C0FF`: чтение клавиатуры, сброс строба, динамик, аналоговые таймеры джойстиков/педалей, переключение видеорежимов.
  - Аутентичные ПЗУ Apple II+: Applesoft BASIC (`$D000` - `$F7FF`) и Autostart Monitor (`$F800` - `$FFFF`).
  - Загрузочное ПЗУ Disk II контроллера в слоте 6 (`$C600` - `$C6FF`).

### 📺 Видеосистема и CRT-эффекты
- **Текстовый режим (40x24)**: знакогенератор оригинального ПЗУ шрифта Apple II 5x7, поддержка Normal, Flash (мигающий) и Inverse (инверсный) текста.
- **Lo-Res Graphics (GR)**: 40x48 (или 40x40 в смешанном режиме Mixed Mode с 4 строками текста внизу), 16 цветов Apple II.
- **Hi-Res Graphics (HGR)**: 280x192 (или 280x160 Mixed Mode), аутентичный рендеринг NTSC композитных цветовых артефактов (Violet, Green, Blue, Orange, White, Black).
- **CRT-фильтры**:
  - Цветной композит (Color Composite)
  - Зеленый фосфор (Green Phosphor в стиле Apple Monitor ///)
  - Винтажный янтарь (Amber CRT)
  - Ч/Б монохром (Monochrome)
  - Эффект строчной развертки (Scanlines toggle) и бликов кинескопа.

### 💾 Дисковая подсистема Disk II (Слот 6)
- Поддержка двух дисководов (Drive 1 и Drive 2).
- Полная эмуляция шагового двигателя (4 фазы, полудорожки 0..69, целые дорожки 0..34).
- Автоматическая нибблизация стандартных 140 КБ `.dsk` образов в GCR 6-and-2 потоки с адресными и данными заголовками (`$D5 $AA $96`, `$D5 $AA $AD`).
- Светодиодная индикация работы дисководов (красные LED-индикаторы активности) и отображение текущей дорожки.
- Встроенная библиотека дискет:
  - **Apple DOS 3.3 System Master** (встроен прямо в код для мгновенного запуска оффлайн)
  - **ProDOS 8 v2.0.3**
  - **Pac-Man Collection**
  - **Falcons (Galaxian)**
- **Drag-and-Drop**: перетаскивание любых файлов `.dsk`, `.do`, `.po` прямо на экран!
- Возможность экспорта / сохранения измененного образа дискеты (кнопка 💾 Save).

### 🔊 Звук
- Web Audio API синтез 1-битного динамика Apple II (`$C030`).
- Реалистичный механический звук шагового мотора дисковода (характерный треск позиционирования головки) и гул вращения шпинделя 5.25" флоппи-привода.
- Регулятор громкости и кнопка выключения звука.

### ⌨️ Управление и ввод
- Захват физической клавиатуры с автотрансляцией специальных клавиш (Return, Backspace/Delete, Arrow Keys, Escape, Ctrl+C, Ctrl+G bell).
- Автоматическая конвертация строчных букв в верхний регистр.
- **Интерактивная виртуальная ретро-клавиатура** прямо на экране для удобной работы на планшетах, смартфонах и мышью.
- **Вставка текста / кода**: всплывающее окно Paste для мгновенного автоввода листингов программ на Applesoft BASIC.

### 🔍 Встроенный отладчик 6502
- Дизассемблер команд реального времени с подсветкой текущего `$PC`.
- Инспектор регистров: `A`, `X`, `Y`, `SP`, `PC`, `P` и флаги процессора (`N`, `V`, `-`, `B`, `D`, `I`, `Z`, `C`).
- Точки останова (Breakpoints) по шестнадцатеричному адресу.
- Пошаговое выполнение инструкций (Step F10) и продолжение выполнения (Go).
- Шестнадцатеричный дамп нулевой страницы и стека (`$0000` - `$007F`).

## 🚀 Быстрый старт на GitHub Pages

Репозиторий готов к развертыванию на GitHub Pages без каких-либо дополнительных шагов сборки:

1. Запушьте код в ветку `main`:
   ```bash
   git add .
   git commit -m "Apple II web emulator initial release"
   git push origin main
   ```
2. Откройте репозиторий на GitHub: `https://github.com/japNslow/AppleII-webemu`.
3. Перейдите в **Settings** -> **Pages**.
4. В разделе **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, папка `/ (root)`
5. Нажмите **Save**. Через 1-2 минуты ваш эмулятор будет доступен по адресу:
   `https://japNslow.github.io/AppleII-webemu/`

## 💻 Локальный запуск

Так как проект использует стандартные модули ES6 (`import`/`export`), его можно запустить локально с помощью любого статического веб-сервера:

### Вариант через Node.js (npx serve):
```bash
npx serve .
```

### Вариант через Python:
```bash
python -m http.server 8080
```
После чего откройте в браузере: `http://localhost:8080`.

## 📁 Структура проекта

```
AppleII-webemu/
├── index.html              # Основная страница веб-приложения
├── css/
│   └── style.css           # Ретро-стилизация корпуса Apple II, ЭЛТ-монитора и клавиатуры
├── js/
│   ├── cpu6502.js          # Ядро процессора MOS 6502 с BCD и адресациями
│   ├── mmu.js              # Управление памятью, софт-свитчи и Language Card
│   ├── video.js            # Генератор графики (Text, Lo-Res, Hi-Res, NTSC, CRT-фильтры)
│   ├── audio.js            # Синтезатор звука динамика $C030 и эффектов дисковода
│   ├── disk2.js            # Контроллер Disk II, нибблизация GCR 6&2, шаговый мотор
│   ├── roms.js             # ПЗУ Apple II+ ($D000-$FFFF), шрифт и Boot ROM Disk II
│   ├── disks.js            # Встроенная библиотека образов дискет
│   ├── keyboard.js         # Обработка клавиатуры и виртуальная клавиатура
│   ├── debugger.js         # Дизассемблер, точки останова и просмотр памяти
│   └── main.js             # Главный оркестратор и пользовательский интерфейс
├── disks/
│   ├── DOS33.dsk           # Apple DOS 3.3 System Master
│   ├── ProDOS8.dsk         # Apple ProDOS 8
│   ├── PacMan.dsk          # Pac-Man Arcade
│   └── Falcons.dsk         # Falcons (Galaxian)
├── tests/
│   └── test_emulator.mjs   # Автоматические тесты работы эмулятора
└── README.md
```
